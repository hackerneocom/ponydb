# Install PonyDB for an AI Agent

Follow the [PonyDB setup runbook](../skills/ponydb/references/setup.md) to install
PonyDB, configure storage, connect the selected CLI or MCP client, and verify a
query. Read that runbook before making setup changes, then load only the
references needed for the selected connection and current step.

When reading remotely, resolve the runbook link relative to this file in the same
release tag or checkout. If you cannot follow relative links, read
`skills/ponydb/references/setup.md` from that version of the PonyDB repository.

If the target Agent already has the complete PonyDB skill installed, use its
bundled `references/setup.md` and reuse the skill installation. Installing the
skill supplies instructions; the executable, storage configuration, credentials,
and database access still need to be available for the selected connection.
